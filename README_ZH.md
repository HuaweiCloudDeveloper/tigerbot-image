## 项目介绍

[TigerBot](https://github.com/TigerResearch/TigerBot) 是一个支持文本创作、逻辑推理、多语言翻译的大语言模型，能够支持多轮对话。本商品基于鲲鹏服务器的Huawei Cloud EulerOS 2.0 64bit系统，提供开箱即用的TigerBot。

## 核心特性

- **多语言支持能力：** 支持中英文及其他主流语言的理解与生成，满足全球化场景下的语言交互需求
- **超大规模参数量：** 基于千亿级参数语言模型，具备强大的语言理解与生成能力，能够胜任复杂文本任务
- **上下文对话理解：** 支持长文本建模与多轮对话记忆，实现更自然、连贯的人机对话体验

本项目提供的开源镜像商品 [TigerBot聊天助手](https://marketplace.huaweicloud.com/hidden/contents/15b6e7e8-6223-41ae-8211-2431b5f5d5af#productid=OFFI1129684170362626048) 已预先安装tigerbot及其相关运行环境，并提供部署模板。快来参照使用指南，轻松开启“开箱即用”的高效体验吧。

> **系统要求如下：**
>
> - CPU: 4vCPUs 或更高
> - RAM: 16GB 或更大
> - Disk: 至少 40GB
