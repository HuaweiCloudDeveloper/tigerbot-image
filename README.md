## Project Introduction



[TigerBot](https://github.com/TigerResearch/TigerBot)  is a large language model that supports text creation, logical reasoning, and multilingual translation, and can support multiple rounds of dialogue.This product provides an out-of-the-box TigerBot based on the Huawei Cloud EulerOS 2.0 64-bit system of Kunpeng servers.

## Core Features

- **Multi language support capability:** Support the understanding and generation of Chinese, English, and other mainstream languages to meet the language interaction needs in the context of globalization
- **Large scale parameter quantity:**Based on a billion level parameter language model, it has strong language understanding and generation capabilities, and is capable of handling complex text tasks
- **Contextual dialogue understanding:**Support long text modeling and multi round dialogue memory to achieve a more natural and coherent human-machine dialogue experience

The open-source image product [TigerBot Chat Assistant](https://marketplace.huaweicloud.com/hidden/contents/15b6e7e8-6223-41ae-8211-2431b5f5d5af#productid=OFFI1129684170362626048) provided by this project has pre-installed the tigerbot and its related runtime environment, and provides deployment templates. Come and refer to the usage guide to easily start an efficient "out-of-the-box" experience!

> **System requirements are as follows:**
>
> - CPU: 4vCPUs or higher
> - RAM: 16GB or larger
> - Disk: At least 40GB
